## WEYI-157

FCM http api with api key authentication is deprecated. 
Current issues exist while we use the deprecated feature.
- legacy api fails with newer Firebase project configurations.
- `Authorization: key=<ServerKey>` header is deprecated.
- Current implementation uses `WebRequest` with hardcoded json and string building.
- We require OAuth 2.0 authentication via **Service Account Credentials** for Firebase [HTTP v1 API](https://fcm.googleapis.com/v1/projects/{projectId}/messages:send)

**Refactor entire FCMPushEngine class to:**

- [ ] Authenticate using `Google.Apis.Auth` and service account JSON.
- [ ] Use `HttpClient` with `async/await`
- [ ] Properly format requests per FCM HTTP vi API specs.
- [ ] Maintain support for `NotificationRecieved`, `NotificationSent`, `NotificationFailed` tracking and status updates.

**Acceptance Criteria**

- [ ] The refactored function can successfully push notifications to device tokens using Firebase Cloud Messaging HTTP v1 API
- [ ] The library includes all necessary C# dependencies (e.g., `Google.Apis.Auth`, `Newtonsoft.Json`) and can be installed cleanly without compile issues when integrated into other projects.
- [ ] Notification status is correctly updated:
	- [ ] `Sent` when push succeeds.
	- [ ] `Failed` when push fails or an error occurs.
