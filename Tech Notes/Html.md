# Checkbox

#### Unchecked
```html
<input type="checkbox" id="vehicle2" name="vehicle2" value="Car" />  
<label for="vehicle2"> I have a car</label><br>
```

> [!example] Example
> <input type="checkbox" name="vehicle2" />
#### Checked
```html
<input type="checkbox" id="vehicle2" name="vehicle2" value="Car" />  
<label for="vehicle2"> I have a car</label><br>
```

> [!example]
> <input type="checkbox" name="vehicle2" checked />
